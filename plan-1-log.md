## Key API Design Issues &amp; Suggestions

### 1. **Duplicated Resource Binding Logic**
   - **Current**: `parse_binding()` appears in CLI, wesl-web, and wesl-c (3× code duplication)
   - **Suggestion**: Export a public `wesl::eval::parse_binding()` helper function
   - **Files**: cli:452, web:236, c:334

### 2. **Resolver/Compiler Setup Boilerplate**
   - **Current**: Every consumer manually does `Wesl::new_barebones()` → `set_options()` → `set_custom_resolver()` → `compile()`
   - **Suggestion**: Add `Wesl::compile_from_files(files: HashMap&lt;String, String&gt;, root: ModulePath, options: CompileOptions)` convenience method
   - **Impact**: Would reduce CLI/web/C code by ~30%

### 3. **Incomplete C API**
   - **Current**: `wesl_create_compiler()` and `wesl_destroy_compiler()` are non-functional stubs
   - **Status**: TODO at line 20 ("this seems unfinished")
   - **Suggestion**: Either remove or implement stateful compiler builder pattern

### 4. **TokRepr Integration Opaque**
   - **Current**: Users of wesl-quote must understand that `.tok_repr()` generates TokenStream
   - **Files**: tokrepr/src/lib.rs defines trait; wgsl-parse uses `#[derive(TokRepr)]` feature
   - **Suggestion**: Document the feature flag dependency chain in wesl-quote README

### 5. **ModulePath Parsing Scattered**
   - **Current**: `ModulePath::from_str()` (lines ~150-180), `ModulePath::from_path()` (lines ~35-80), `new()`, `new_root()` all separate
   - **Suggestion**: Consolidate into a single builder API

### 6. **Error Context Loss in FFI**
   - **Current**: wesl-c converts `wesl::Error` → `WeslError` struct, losing original Rust error chain
   - **Suggestion**: Return error chain metadata (cause, context) in C struct for better diagnostics

### 7. **Feature Flag Fragmentation**
   - **Current**: Feature flags at three levels: crate features (`eval`, `generics`, `package`), `CompileOptions` bools, and conditional compilation flags
   - **Suggestion**: Document the interaction clearly; consider a single unified feature API

```rust
pub fn compile(root: &amp;ModulePath, resolver: &amp;impl Resolver, mangler: &amp;impl Mangler,
               options: &amp;CompileOptions) -&gt; Result&lt;CompileResult, Error&gt; {
    let (mut resolutions, keep) = compile_pre_assembly(root, resolver, options)?;
    resolutions.mangle(mangler, options.mangle_root);
    let mut assembly = resolutions.assemble(options.strip &amp;&amp; options.lazy);
    let modules = resolutions.into_module_order();
    compile_post_assembly(&amp;mut assembly, options, &amp;keep)?;
    Ok(CompileResult { syntax: assembly, sourcemap: None, modules })
}

pub fn compile_sourcemap(root: &amp;ModulePath, resolver: &amp;impl Resolver, mangler: &amp;impl Mangler,
                        options: &amp;CompileOptions) -&gt; Result&lt;CompileResult, Error&gt; {
    let sourcemapper = SourceMapper::new(root, resolver, mangler);
    match compile_pre_assembly(root, &amp;sourcemapper, options) {
        Ok((mut resolutions, keep)) =&gt; {
            resolutions.mangle(&amp;sourcemapper, options.mangle_root);
            let sourcemap = sourcemapper.finish();
            let mut assembly = resolutions.assemble(options.strip &amp;&amp; options.lazy);
            let modules = resolutions.into_module_order();
            compile_post_assembly(&amp;mut assembly, options, &amp;keep)
                .map_err(|e| Diagnostic::from(e).with_output(...).with_sourcemap(&amp;sourcemap)...)?;
            Ok(CompileResult { syntax: assembly, sourcemap: Some(sourcemap), modules })
        }
        Err(e) =&gt; { let sourcemap = sourcemapper.finish(); Err(...) }
    }
}
```

### 9. Pipeline Architecture and Design Constraints

**Compilation Pipeline** (from lib.rs and module structure):

```
Input (WESL source)
    ↓
[1] RESOLVE — Load module sources via Resolver
    ├─ FileResolver (filesystem)
    ├─ VirtualResolver (in-memory)
    ├─ PkgResolver (Cargo packages)
    ├─ Router (dispatch by prefix)
    └─ Preprocessor (transform sources)
    ↓
[2] IMPORT PROCESSING (import.rs)
    ├─ Flatten import statements
    ├─ Load modules lazily or eagerly (per CompileOptions::lazy)
    ├─ Retarget identifiers to actual declarations
    └─ Preserve `@publish` visibility
    ↓
[3] CONDCOMP — Evaluate @if/@elif/@else (condcomp.rs)
    ├─ Based on CompileOptions::features
    └─ Strips unevaluated branches
    ↓
[4] MANGLE — Rename identifiers (mangle.rs)
    ├─ EscapeMangler (default): `foo::bar::item` → `_1foo_bar_item`
    ├─ HashMangler: `foo::bar::item` → `item_1985638328947`
    ├─ UnicodeMangler: Uses unicode lookalikes
    └─ NoMangler: No mangling
    ↓
[5] VALIDATE (optional) — Check for undefined symbols, duplicates, cycles
    ↓
[6] STRIP — Dead code elimination (if enabled)
    ├─ Keep entry points (@compute/@vertex/@fragment)
    ├─ Keep declarations in CompileOptions::keep
    ├─ Keep declarations in CompileOptions::keep_root
    └─ Remove unused declarations
    ↓
[7] LOWER (optional, eval feature) — Transforms for compatibility
    ├─ Remove type aliases (inline)
    ├─ Remove const declarations (inline)
    ├─ Evaluate const-expressions (if eval feature)
    └─ Remove unreachable code
    ↓
[8] SOURCEMAP (optional) — Record file→mangled name mappings
    ↓
```

# SYNC/ASYNC strategy for the `wesl` compilation pipeline

## 0. Ground truth from the code (what constrains the design)

**The I/O surface is exactly two call sites.** `resolver.resolve_module(path)` inside `load_module` (import.rs:141), and the root-module load in `compile_pre_assembly` (lib.rs:853). Everything downstream of `Resolutions` (retarget, mangle, assemble, validate, lower, strip) is pure CPU and never touches the resolver.

**But the loading is interleaved with a 5-participant recursion.** The load site sits in the middle of mutually recursive functions, with `Ref&lt;Module&gt;` borrows and `&amp;Module` references threaded through every frame:

```rust
// import.rs:162-166  (load_module_with_source) — onload runs UNDER a Ref borrow
{
    let module = module.borrow();
    onload(&amp;module, resolutions, resolver)          // -&gt; resolve_ty -&gt; load_module -&gt; I/O
        .map_err(|e| err_with_module(e, &amp;module, resolver))?;
}

// import.rs:246-251  (resolve_ty) — Ref acquired, then MORE loading under it
let ext_mod = load_module(&amp;ext_path, resolutions, resolver, &amp;onload)?;   // I/O
let ext_mod = ext_mod.borrow();
resolve_decl(&amp;ext_mod, ext_id, resolutions, resolver, onload)            // -&gt; more I/O
    .map_err(|e| err_with_module(e, &amp;ext_mod, resolver))
```

The recursion cycle is `resolve_ty ↔ resolve_decl ↔ load_module → load_module_with_source → onload(fn item) → resolve_ty`, plus two self-edges (`resolve_ty→resolve_ty` for nested type expressions, `resolve_decl→resolve_decl` for `@publish` re-export chains).

**Three behaviors are encoded in the recursion structure and must not drift:**
1. *Module order.* `Resolutions.order` is push-on-first-load, i.e. DFS discovery order (import.rs:111-117). `assemble()` emits declarations in that order — it is user-visible output.
2. *Error attribution.* `Diagnostic::with_module_path` only sets if `None` (error.rs:180), so the **innermost** `err_with_module` wrap wins — the module actually being traversed when the error occurred. Any restructure that changes where wraps happen changes error messages.
3. *Cycle protection.* `used_idents.borrow_mut().insert(ident)` before recursing (import.rs:183).

**The import machinery is private.** `mod import;` (lib.rs:16) only re-exports `ImportError`; `resolve_lazy`, `resolve_eager`, `Resolutions`, `load_module*` are free to change signature with zero public breakage.

**Internal dyn usage is incidental, not essential.** `compile_pre_assembly` boxes `Box&lt;dyn Resolver&gt;` (lib.rs:844-851) *only* to unify the "Preprocessor or not" branch. `SourceMapper` holds `&amp;dyn Resolver` (sourcemap.rs:114) *only* to avoid a generic parameter. The genuinely public dyn users are `Router` (resolve.rs:278) and wesl-c (`Box&lt;dyn wesl::Resolver&gt;`, wesl-c/src/lib.rs:659) — both sync.

## 1. Recommendation

**Hybrid of (a), corrected: an `AsyncResolver` trait (AFIT, no Send bound) + the core pipeline written once as async fns + a private ~15-line no-op-waker "poll once" driver for the sync path + an adapter struct instead of a blanket impl.** Plus one targeted restructure that dissolves the wrapper problem: replace the internal `Preprocessor`-wrapping and `SourceMapper`-as-resolver with loader-level hooks (a sync per-module transform closure and an optional `RefCell&lt;BasicSourceMap&gt;` recording slot), so **only one trait ever needs an async form: `Resolver` itself.**

Key insight that makes (a) safe and dependency-free: an `async fn` whose awaits are all on futures that are `Ready` at first poll **completes in exactly one poll** — that is guaranteed by the `.await` desugaring (it only returns `Pending` when an inner poll returns `Pending`). The sync entry point wraps the user's `impl Resolver` in an adapter whose async methods contain **zero awaits**, so the entire compile future is single-poll by construction. The driver never parks, needs no executor, and works on wasm (unlike `pollster::block_on`, which is also why (d) is rejected). Misuse is a *type error*, not a runtime hazard: the sync API only accepts `impl Resolver`, so a truly-async future can never reach the sync driver.

### Honest assessment of the alternatives

**(a) as literally proposed — blanket `impl&lt;T: Resolver&gt; AsyncResolver for T` — does not survive coherence.** The async side needs `impl AsyncResolver for Box&lt;T&gt;` and `for &amp;T` (mirroring resolve.rs:58-86, required so the generic core accepts borrowed/boxed resolvers). Both overlap with the blanket impl because `Box&lt;U: Resolver&gt;: Resolver` and `&amp;U: Resolver` already hold. This is exactly where such designs break; the fix is a zero-cost adapter struct (`AsAsync&lt;R&gt;`) and explicit wrapping inside the sync entry points — users never see it.

**(b) sans-io state machine: rejected as the implementation strategy, because (a′) subsumes it.** Feasibility is real but expensive: suspending by *returning* (instead of awaiting) means no `Ref&lt;Module&gt;` borrow can live across a suspension, so the 5-participant recursion must be reified into an explicit stack of *owned* frames (module path + decl index + position within a `Visit&lt;TypeExpression&gt;` walk — and `Visit` iterators borrow the AST inside the `Rc&lt;RefCell&lt;…&gt;&gt;` owned by the same session → self-referential unless you switch to owned worklists of `(ModulePath, Ident)` pairs). That rewrite must then hand-maintain the three encoded behaviors above (DFS emission order via careful LIFO discipline, innermost-error attribution, mark-before-recurse). It is a rewrite of the ~250 lines the author annotated `// XXX: it's quite messy.` (import.rs:254). Meanwhile, `async fn` gets the compiler to generate precisely that state machine from the *unchanged* recursion — borrows across suspension points included, because await does not release borrows. If a public pull-based API ("`session.next_needed_module()`") is ever wanted, it can be layered on the async core later via a request-cell resolver; the algorithm never needs rewriting again. (Caveat to note then: a self-contained session type would hold a future borrowing its own resolver — needs `Box::pin` + ownership care.)

**(c) maybe-async / macro duplication: rejected.** Two compiled artifacts to test, rustdoc shows the macro soup or duplicated items, breakpoints/backtraces land in generated code, and the recursive-future boxing is needed in the async expansion anyway — so you pay AFIT's costs *plus* the macro's.

**(d) async-only core + `pollster`: rejected, but for a sharper reason than the dep.** `pollster::block_on` would actually work for always-ready futures without parking; the real problems are (i) a new dependency on the build.rs path, and (ii) it converts "async resolver passed to sync compile" from a compile-time type error into a runtime deadlock/panic. Our sync driver's `unreachable!` arm is enforceable by construction; pollster's is not.

**Send bounds: futures are `!Send`, and that is the right call for v1.** `Resolutions` is `Rc&lt;RefCell&lt;Module&gt;&gt;` and `Ref` guards are held across await points (see §4), so the compile future is `!Send` regardless of the trait. Do **not** put `Send` bounds on `AsyncResolver` (that would exclude `JsFuture` on wasm, the primary async consumer). This is a non-breaking upgrade path: `compile_async` returns `impl Future`; *adding* `Send` later (by migrating `Resolutions` from `Rc&lt;RefCell&gt;` to an index/arena scheme) strengthens the type without breaking any caller. Bevy-style multithreaded executors meanwhile use `spawn_local`/a dedicated thread/channel bridge — document it.

## 2. Exact definitions

### 2.1 The traits (resolve.rs)

`Resolver` survives **byte-for-byte unchanged** (resolve.rs:34-56). New, alongside it:

```rust
/// Async counterpart of [`Resolver`]. Implementations may perform I/O
/// (network, JS Promises, asset pipelines) while resolving modules.
///
/// Returned futures are not required to be `Send`.
/// Every [`Resolver`] can be used where an `AsyncResolver` is expected
/// via [`AsAsync`] (the sync entry points do this automatically).
pub trait AsyncResolver {
    async fn resolve_source&lt;'a&gt;(&amp;'a self, path: &amp;ModulePath)
        -&gt; Result&lt;Cow&lt;'a, str&gt;, ResolveError&gt;;

    async fn resolve_module(&amp;self, path: &amp;ModulePath)
        -&gt; Result&lt;TranslationUnit, ResolveError&gt;
    {
        let source = self.resolve_source(path).await?;
        let wesl: TranslationUnit = source.parse().map_err(|e| {
            Diagnostic::from(e)
                .with_module_path(path.clone(), self.display_name(path))
                .with_source(source.to_string())
        })?;
        Ok(wesl)
    }

    // metadata stays sync — it is cheap bookkeeping, and keeping it sync
    // lets SourceMapper/diagnostics call it without awaiting.
    fn display_name(&amp;self, _path: &amp;ModulePath) -&gt; Option&lt;String&gt; { None }
    fn fs_path(&amp;self, _path: &amp;ModulePath) -&gt; Option&lt;PathBuf&gt; { None }
}

impl&lt;T: AsyncResolver + ?Sized&gt; AsyncResolver for &amp;T { /* forward */ }
impl&lt;T: AsyncResolver + ?Sized&gt; AsyncResolver for Box&lt;T&gt; { /* forward */ }

/// Adapter making any sync [`Resolver`] usable as an [`AsyncResolver`].
/// Its futures never suspend (no `.await` in the bodies) — this is the
/// invariant the sync driver in lib.rs relies on.
pub struct AsAsync&lt;R&gt;(pub R);

impl&lt;R: Resolver&gt; AsyncResolver for AsAsync&lt;R&gt; {
    async fn resolve_source&lt;'a&gt;(&amp;'a self, path: &amp;ModulePath)
        -&gt; Result&lt;Cow&lt;'a, str&gt;, ResolveError&gt; { self.0.resolve_source(path) }
    async fn resolve_module(&amp;self, path: &amp;ModulePath)
        -&gt; Result&lt;TranslationUnit, ResolveError&gt; { self.0.resolve_module(path) }
    fn display_name(&amp;self, path: &amp;ModulePath) -&gt; Option&lt;String&gt; { self.0.display_name(path) }
    fn fs_path(&amp;self, path: &amp;ModulePath) -&gt; Option&lt;PathBuf&gt; { self.0.fs_path(path) }
}
```

AFIT (not hand-boxed futures) because the core is generic and, after the restructure below, **nothing in the crate needs `dyn AsyncResolver`**. If an `AsyncRouter` is wanted later, implement it with a *private* dyn bridge inside its module (`trait DynAsyncResolver { fn resolve_source_boxed&lt;'a&gt;(&amp;'a self, path: &amp;'a ModulePath) -&gt; Pin&lt;Box&lt;dyn Future&lt;Output = …&gt; + 'a&gt;&gt;; }` + blanket over `AsyncResolver` + `AsyncRouter` storing `Box&lt;dyn DynAsyncResolver&gt;`); users only ever see `AsyncRouter: AsyncResolver`. Deferred — not needed by wesl-web, wesl-c, or the pipeline.

### 2.2 The sync driver (lib.rs, private, ~15 lines, zero deps)

```rust
/// Drive a future that is known to complete without suspending.
/// Sound because the sync entry points only ever construct futures whose
/// awaits are on `AsAsync` methods, which contain no `.await`.
fn block_on_ready&lt;F: Future&gt;(fut: F) -&gt; F::Output {
    let mut fut = std::pin::pin!(fut);
    let mut cx = std::task::Context::from_waker(std::task::Waker::noop()); // stable 1.85, MSRV 1.96 ok
    match fut.as_mut().poll(&amp;mut cx) {
        std::task::Poll::Ready(out) =&gt; out,
        std::task::Poll::Pending =&gt; unreachable!(
            "the sync pipeline awaits only immediately-ready futures; \
             a `.await` on a suspending future was introduced into the core"
        ),
    }
}
```

### 2.4 Preprocessor and sourcemap in both worlds: loader-level hooks

The per-module transform is conceptually a *pipeline stage applied at load time*, not a resolver concern. Internally (import.rs):

```rust
#[derive(Clone, Copy)]
pub(crate) enum Strategy { Lazy, Eager }   // replaces the two `onload` fn items

pub(crate) struct Loader&lt;'a, R: AsyncResolver&gt; {
    resolver: &amp;'a R,
    strategy: Strategy,
    /// condcomp etc. Sync: pure CPU. Applied to every module incl. root.
    preprocess: Option&lt;&amp;'a dyn Fn(&amp;mut TranslationUnit) -&gt; Result&lt;(), Error&gt;&gt;,
    /// sourcemap recording (module source + display name), both paths.
    record: Option&lt;&amp;'a RefCell&lt;BasicSourceMap&gt;&gt;,
}
```

`load_module` becomes (schematically): resolve → on preprocess error, re-fetch source for the diagnostic exactly as `Preprocessor::resolve_module` does today (resolve.rs:253-261: `with_module_path(...).with_source(self.resolve_source(path)...)` — error path only) → record source if `record` is set (what `SourceMapper::resolve_source` does at sourcemap.rs:144-151). The public sync `Preprocessor` stays exported and functional for external users (and composes with async compiles via `AsAsync`); it is simply no longer used internally. This *removes* a generic parameter from the recursion (the `&amp;impl Fn` onload threading) — the async core ends up simpler than today's sync core.

### 2.5 Recursive async fns: where the `Box::pin` goes

Rust rejects unboxed recursive async fns (infinitely sized future). Cycle edges and the minimal boxing that breaks them, chosen to keep the hot path allocation-free:

- `resolve_decl` → **fn-level boxed**: `fn resolve_decl&lt;'a, R: AsyncResolver&gt;(…) -&gt; Pin&lt;Box&lt;dyn Future&lt;Output = Result&lt;(), Error&gt;&gt; + 'a&gt;&gt; { Box::pin(async move { /* body unchanged */ }) }` (called once per used decl — cold).
- `resolve_ty` → stays a plain `async fn`; only its **self-recursive call site** (import.rs:217-219, nested type expressions) becomes `Box::pin(resolve_ty(…)).await`. Leaf `resolve_ty` calls — the overwhelming majority (every identifier in every used decl body) — allocate nothing.
- `load_module`, `load_module_with_source`, `on_module_loaded(strategy, …)` → plain `async fn`s; their futures contain only the boxed children, so they size finitely.

Cycle check: ty→ty (call-site boxed), ty→decl (fn-boxed), decl→decl (fn-boxed), decl→ty (plain future embedded inside decl's box — finite because *its* recursion edges are boxed), loaded-hook→ty (plain). All broken. Cost: O(used decls) + O(nested generic types) boxes per compile — noise next to `assemble()` cloning every global declaration (import.rs:577-595).

### 2.6 Error flow

Unchanged. `ResolveError`, `ImportError`, `Diagnostic` and every `err_with_module`/`map_err` site keep their exact positions in the (now async) recursion, so the innermost-wins attribution (error.rs:180) produces identical messages. The only error-adjacent change is reproducing `Preprocessor`'s on-error source fetch in the loader (§2.4).

## 4. The RefCell-across-await audit (rigorous)

Await points in the async core are exactly the old I/O sites plus the boxed recursion awaits. Inventory of what is live across them:

- **`Ref&lt;'_, Module&gt;` (shared borrows) — yes, held across awaits**, in the same places the sync code holds them across `resolve_module` calls: `load_module_with_source`'s onload block (import.rs:162-166), `resolve_ty`'s post-load `ext_mod.borrow()` (246-251), `resolve_decl`'s re-export branch (196-199), `resolve_lazy`'s keep loop (303-309). This is *sound*: (i) suspension does not release borrows, and nothing else can touch this `Resolutions` while suspended — it is a local of the compile future, never shared; (ii) a conflicting `borrow_mut` cannot occur, because module-level `borrow_mut` happens in exactly two places — on a freshly created module inside `load_module_with_source` (import.rs:156-160), which by the early-return in `load_module` (import.rs:137-139) is never an already-borrowed module, and in `retarget`/`mangle`, which run strictly after resolution with no borrows outstanding (scope at import.rs:303-309 closes before `retarget()` at 311). The borrow discipline is *position-identical* to the sync code; async adds suspension points but changes no borrow lifetimes. Consequence: the future is `!Send` (`Ref`, `Rc` in state) — accepted and documented (§1).
- **`RefMut` — never held across an await.** The two `borrow_mut`s during resolution are: the fresh-module setup block (156-160, dropped before onload's awaits) and `used_idents.borrow_mut().insert(…)` (183) — a temporary inside an `if` condition on a *separate* `RefCell` field, dropped at the end of the condition. `SourceMapper`-style recording in the loader likewise acquires `record.borrow_mut()` only *after* the resolver future completes.
- **`&amp;mut Resolutions` across awaits** — plain exclusive reference in the future's state, reborrowed into each boxed child future and returned at each `.await` — the standard async-recursion pattern; no runtime component.

No new panic paths, no `BorrowMutError` risk that does not already exist in the sync code (there is none), no unsafe.

# Design: Pipeline Pass System + Sourcemap v2 for the `wesl` crate

## Verified facts the design rests on

1. **Per-module transform at load time already exists** as `Preprocessor` (resolve.rs:228-269), used internally only once (lib.rs:844-851) to run condcomp. Its `ResolveFn` closure gets `&amp;mut TranslationUnit` but **not the module path** (resolve.rs:225-226), so it cannot be reused as-is for a ctx-aware pass system. `Preprocessor` has no other users in the workspace (verified by grep) — internal replacement is safe; the public type can stay.
2. **Module passes must run at load time**: `load_module_with_source` (import.rs:145-169) builds the ident lookup map, flattens imports, retargets idents, and runs usage discovery (`onload`) immediately after `resolver.resolve_module()` returns. A pass running inside `resolve_module` therefore sees the module *before* any bookkeeping — it may freely add/remove/rename declarations and even add `import` statements; everything downstream (usage analysis, mangling, assembly) picks them up. This is the single most powerful hook point.
3. **Spans survive assembly**: `assemble()` (import.rs:572-603) clones `Spanned&lt;GlobalDeclaration&gt;` nodes wholesale, so each declaration in the final unit keeps its span **in the original module's source coordinates**. Renames via `Ident::rename` (syntax.rs:66) and condcomp attribute removal never touch spans.
4. **The use_count trap (critical)**: `strip_except` keeps any declaration with `id.use_count() &gt; 1` (strip.rs:12); validation's undefined-symbol check uses `use_count() == 1` (validate/mod.rs:40); `lower` deliberately scopes a clone to control counts (lower.rs:47-55). **A sourcemap holding strong `Ident` clones during `compile_post_assembly` would inflate every declaration's count and disable stripping entirely.** The provenance map must use weak handles.
5. **Per-decl Display is real**: `GlobalDeclaration: Display` (syntax_display.rs:161-171), `Spanned&lt;T: Display&gt;` forwards (syntax_display.rs:16-20), and `TranslationUnit::fmt` just prints imports, directives (`"\n"`-joined + `"\n\n"`), then non-Void decls `"\n\n"`-joined with trailing newline (syntax_display.rs:36-55). A comment-injecting writer can reproduce this byte-for-byte. The lexer skips comments via logos callbacks (lexer.rs:279-281); there are **no comment nodes** in the AST.
6. **Error line numbers already work** when a span+source are known: `Diagnostic::fmt` feeds `annotate-snippets` a `Snippet::source(...).annotation(span.range())` (error.rs:557-579) which renders line/col itself. What's missing today: decl-level spans are never recorded, root (unmangled) decls are absent from the sourcemap (`XXX` comment at error.rs:243), and there is no programmatic line/col API.
7. `Error::Custom(String)` exists (error.rs:41) and `Error` is `Clone` (error.rs:20) — so pass errors can't be `Box&lt;dyn Error&gt;`; they should just be `crate::Error`.
8. `Wesl` stores `mangler: Box&lt;dyn Mangler + Send + Sync + 'static&gt;` (lib.rs:238) and `compile` takes `&amp;self` (lib.rs:765) — passes must be `Fn`-style (`&amp;self`) and should carry `Send + Sync` to keep `Wesl&lt;R&gt;`'s auto-traits unchanged.
9. `SyntaxNode::ident()` returns an **owned** `Option&lt;Ident&gt;` clone (syntax_impl.rs:514, 543) — transient count bump only. `FromStr for GlobalDeclaration` exists (parser.rs:86). `entry_points()` returns `impl Iterator&lt;Item = &amp;Ident&gt;` (syntax_util.rs:33).

# Part 1 — Pass/hook system

## 1.1 Hook points

| Stage | When | State available | Why here |
|---|---|---|---|
| **`ModuleLoad`** (per module) | Inside `resolve_module`, after parse + builtin condcomp, before ident-map/flatten/retarget/usage-discovery (import.rs:145-169); root module included (lib.rs:853) | one module's `&amp;mut TranslationUnit`, its `ModulePath`, root path, options/features. Original names, original spans, imports still present | The only point compatible with lazy resolution: usage discovery reads the module immediately after load, so transforms must happen first. Additions/renames/new imports here are fully integrated by all later steps, including `keep_idents` for the root (lib.rs:853-854) |
| **`ResolutionComplete` / PreMangle** (module set) — *designed, deferred to phase 2* | After `compile_pre_assembly` returns, before `resolutions.mangle` (lib.rs:910-911 / 932-934) | all modules as `(&amp;ModulePath, &amp;mut TranslationUnit)`, original names intact | Only place with the whole program *and* original names *and* module boundaries. Deferred because usage bookkeeping (`used_idents`, import.rs:44) is already frozen: under `strip &amp;&amp; lazy`, decls added here are silently dropped by `assemble`'s filter (import.rs:582-588). Needs a guarded facade (below) |
| **`PostAssembly`** (whole program) | Top of `compile_post_assembly`, before generics/validate/lower/strip (lib.rs:885-898) | single merged `&amp;mut TranslationUnit`, mangled names, spans intact, `keep` set applies afterwards | First point where "the WGSL program" exists as one unit; output still gets validated/lowered/stripped, so pass mistakes are caught. Ident-based `keep`/strip is rename-safe |
| **`Final`** (whole program) | End of `compile_post_assembly`, after strip, before stringification | final `&amp;mut TranslationUnit` exactly as it will be printed | Post-processing that must not be altered by lower/strip (e.g. renaming entrypoints for a variant, attribute injection). Not validated — documented; users can call the public `validate_wgsl` themselves |

Considered and rejected: *source-text hook* (that's `Resolver` wrapping — `Preprocessor` already covers it); *post-parse-before-condcomp* (disable condcomp and run your own instead); *post-mangle-pre-assembly* (no state PostAssembly doesn't have — assembly is pure concatenation); *pre-strip* (`Stage` is `#[non_exhaustive]`, can be added later).

```rust
/// Per-module transform, run each time a module is loaded (after parsing and

    fn name(&amp;self) -&gt; &amp;str { "&lt;program pass&gt;" }

}

impl&lt;F&gt; ModulePass for F
where F: Fn(&amp;mut TranslationUnit, &amp;ModuleCtx) -&gt; Result&lt;(), Error&gt; + Send + Sync {
    fn run(&amp;self, module: &amp;mut TranslationUnit, ctx: &amp;ModuleCtx) -&gt; Result&lt;(), Error&gt; {
        self(module, ctx)
    }
}
impl&lt;F&gt; ProgramPass for F
where F: Fn(&amp;mut TranslationUnit, &amp;ProgramCtx) -&gt; Result&lt;(), Error&gt; + Send + Sync {
    fn run(&amp;self, unit: &amp;mut TranslationUnit, ctx: &amp;ProgramCtx) -&gt; Result&lt;(), Error&gt; {
        self(unit, ctx)
    }
}

/// Pass registry. Kept out of `CompileOptions` because that struct derives
/// `Clone + PartialEq + Eq` (lib.rs:67) which boxed passes cannot satisfy.
#[derive(Default)]
pub struct Passes {
    pub module: Vec&lt;Box&lt;dyn ModulePass&gt;&gt;,
    pub post_assembly: Vec&lt;Box&lt;dyn ProgramPass&gt;&gt;,
    pub finalize: Vec&lt;Box&lt;dyn ProgramPass&gt;&gt;,
}
impl Passes {
    pub fn add_program_pass(&amp;mut self, stage: Stage, pass: impl ProgramPass + 'static) {
        match stage {
            Stage::PostAssembly =&gt; self.post_assembly.push(Box::new(pass)),
            Stage::Final =&gt; self.finalize.push(Box::new(pass)),
        }
    }
}
```

Rationale:
- **Traits over bare closures**: object-safe (`run(&amp;self, ..)` with concrete types only — note `SyntaxNode` is *not* object-safe due to its generic `retain_attributes_mut`, so we can't lean on it), nameable for diagnostics, stateful passes possible; blanket impls keep closure ergonomics. The two blanket impls don't overlap (distinct ctx types). Known wart: inline closures usually need parameter type annotations to satisfy the HRTB (`|m: &amp;mut TranslationUnit, ctx: &amp;ModuleCtx| ...`); document it.
- **`Fn`, not `FnMut`**: `Wesl::compile` takes `&amp;self` (lib.rs:765); passes needing state use interior mutability (e.g. `Mutex`) — same constraint the `Resolver`/`Mangler` traits already impose.
- **`Send + Sync` supers**: matches the mangler box (lib.rs:238); keeps `Wesl&lt;R&gt;: Send + Sync ⇔ R: Send + Sync` unchanged.
- **Error type**: passes return `crate::Error`. `Error` is `Clone` so `Box&lt;dyn Error&gt;` payloads are out; users use `Error::Custom(String)` or any existing variant. Add a convenience constructor in error.rs: `impl Error { pub fn custom(msg: impl std::fmt::Display) -&gt; Self { Self::Custom(msg.to_string()) } }`.
- **Sourcemap-under-construction in ctx**: rejected for v1 (would force `RefCell` plumbing through `ModuleCtx` and couple the systems); synthesized decls simply carry no provenance, which Part 2 handles uniformly.

```rust
pub(crate) struct HookedResolver&lt;'a&gt; {
    pub resolver: &amp;'a dyn Resolver,
    pub root: &amp;'a ModulePath,
    pub options: &amp;'a CompileOptions,
    pub passes: &amp;'a [Box&lt;dyn ModulePass&gt;],
}
impl Resolver for HookedResolver&lt;'_&gt; {
    fn resolve_source&lt;'b&gt;(&amp;'b self, path: &amp;ModulePath) -&gt; Result&lt;Cow&lt;'b, str&gt;, ResolveError&gt; {
        self.resolver.resolve_source(path)
    }
    fn resolve_module(&amp;self, path: &amp;ModulePath) -&gt; Result&lt;TranslationUnit, ResolveError&gt; {
        let mut wesl = self.resolver.resolve_module(path)?;
        let wrap = |e: Error, pass: Option&lt;&amp;str&gt;| -&gt; ResolveError {
            let e = match pass {
                Some(n) =&gt; Error::Custom(format!("in pass `{n}`: {e}")),
                None =&gt; e,
            };
            Diagnostic::from(e)
                .with_module_path(path.clone(), self.resolver.display_name(path))
                // NOTE: no `.unwrap()` unlike Preprocessor (resolve.rs:258)
                .with_source(self.resolver.resolve_source(path)
                    .map(|s| s.to_string()).unwrap_or_default())
                .into()
        };
        if self.options.condcomp {
            condcomp::run(&amp;mut wesl, &amp;self.options.features).map_err(|e| wrap(e, None))?;
        }
        let ctx = ModuleCtx { path, root: self.root, options: self.options };
        for pass in self.passes {
            pass.run(&amp;mut wesl, &amp;ctx).map_err(|e| wrap(e, Some(pass.name())))?;
        }
        Ok(wesl)
    }
    fn display_name(&amp;self, p: &amp;ModulePath) -&gt; Option&lt;String&gt; { self.resolver.display_name(p) }
    fn fs_path(&amp;self, p: &amp;ModulePath) -&gt; Option&lt;PathBuf&gt; { self.resolver.fs_path(p) }
}
```

# Part 2 — Sourcemap v2

## 2.1 Data model and where it's built

**Key insight / constraint chain**: name keys break under rename passes and miss unmangled root decls; parallel index arrays break under strip/lower reordering (`swap_remove` in lower.rs:77); embedding `ModulePath` in AST nodes means invasive wgsl-parse changes (every constructor, serde/tokrepr derives); strong `Ident` keys break stripping (fact 4); spans can't disambiguate the origin module (two files both have a decl starting at offset 0). The one identity that is stable, cheap, and side-effect-free is a **weak handle to the `Ident` Arc**.

**wgsl-parse addition** (syntax.rs, next to `Ident`, ~30 lines, purely additive):

```rust
impl Ident {
    /// Downgrade to a weak handle. Does NOT count towards [`Ident::use_count`].
    pub fn downgrade(&amp;self) -&gt; WeakIdent { WeakIdent(Arc::downgrade(&amp;self.0)) }
}

/// Weak counterpart of [`Ident`]. Equality/hash follow ident identity (pointer),
/// consistent with `Ident`'s `Hash` (syntax.rs:92-96, hashes the pointee address).
#[derive(Clone, Debug)]
pub struct WeakIdent(Weak&lt;RwLock&lt;String&gt;&gt;);
impl WeakIdent {
    pub fn upgrade(&amp;self) -&gt; Option&lt;Ident&gt; { self.0.upgrade().map(Ident) }
}
impl PartialEq for WeakIdent { fn eq(&amp;self, o: &amp;Self) -&gt; bool { Weak::ptr_eq(&amp;self.0, &amp;o.0) } }
impl Eq for WeakIdent {}
impl std::hash::Hash for WeakIdent {
    fn hash&lt;H: std::hash::Hasher&gt;(&amp;self, h: &amp;mut H) { std::ptr::hash(self.0.as_ptr(), h) }
}
```

Soundness note (important, non-obvious): while a `WeakIdent` lives in the map, the `ArcInner` allocation cannot be freed (weak count ≥ 1), so its address is never reused — **pointer-keyed lookup can never produce a false match**, even for idents whose strong count dropped to zero (stripped decls). Memory cost: one dead `RwLock&lt;String&gt;` shell per stripped decl until the sourcemap drops (the `String` buffer itself is freed) — negligible.

**wesl sourcemap.rs — new model** (public field-private struct; all existing methods preserved):

```rust
/// Provenance of one output declaration.
#[derive(Clone, Debug)]
pub struct DeclProvenance {
    /// Module the declaration was written in.
    pub path: ModulePath,
    /// Original (pre-mangling) declaration name.
    pub name: String,
    /// Span of the whole declaration in the original module source.
    /// `None` for synthesized declarations (their span is the empty default).
    pub span: Option&lt;Span&gt;,
}

#[derive(Clone, Debug, Default)]
pub struct BasicSourceMap {
    decls: Vec&lt;DeclProvenance&gt;,
    by_name: HashMap&lt;String, usize&gt;,     // final/output name -&gt; decls index (replaces `mappings`)
    by_ident: HashMap&lt;WeakIdent, usize&gt;, // ident identity -&gt; decls index (rename-proof)
    sources: HashMap&lt;ModulePath, (Option&lt;String&gt;, String)&gt;, // unchanged
    default_source: Option&lt;String&gt;,                          // unchanged
}

impl BasicSourceMap {
    // unchanged: new(), add_source(), set_default_source()
    // kept, reimplemented: add_decl(decl, path, item) pushes DeclProvenance{span:None} + by_name entry
    pub fn add_provenance(&amp;mut self, ident: WeakIdent, path: ModulePath,
        name: String, span: Option&lt;Span&gt;) -&gt; usize;
    pub(crate) fn index_output_names(&amp;mut self); // for each (weak,idx): upgrade -&gt; by_name[current name]=idx
    pub fn provenance_of(&amp;self, ident: &amp;Ident) -&gt; Option&lt;&amp;DeclProvenance&gt; {
        self.by_ident.get(&amp;ident.downgrade()).map(|i| &amp;self.decls[*i])
    }
    pub fn provenance_by_name(&amp;self, name: &amp;str) -&gt; Option&lt;&amp;DeclProvenance&gt;;
    /// Resolve file/line/col for a declaration of the output syntax tree.
    pub fn decl_location(&amp;self, ident: &amp;Ident) -&gt; Option&lt;DeclLocation&lt;'_&gt;&gt;;
}

/// Computed, borrowed view combining provenance with file name and line/col.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct DeclLocation&lt;'a&gt; {
    pub path: &amp;'a ModulePath,
    pub name: &amp;'a str,           // original declaration name
    pub file: Option&lt;&amp;'a str&gt;,   // Resolver::display_name, e.g. "src/shaders/bar.wesl"
    pub line: Option&lt;u32&gt;,       // 1-based; None if synthesized or source missing
    pub col: Option&lt;u32&gt;,        // 1-based, counted in Unicode scalar values
}
```

Line/col is computed **lazily from the stored sources** (`sources` already caches every loaded module — `SourceMapper::resolve_source`, sourcemap.rs:144-151, is hit for every module because the default `resolve_module` calls it, resolve.rs:38-46). Helper in sourcemap.rs:

```rust
/// 1-based (line, col); col counts chars since the last newline.
fn line_col(source: &amp;str, byte_offset: usize) -&gt; (u32, u32)
```

No memoization struct (would need `RefCell`, costing `Sync`); the batch annotator below builds a per-call line-start index instead.

**`SourceMap` trait** gains only defaulted methods (non-breaking for external impls; `Option&lt;T&gt;` and `NoSourceMap` impls inherit defaults):

```rust
fn get_provenance(&amp;self, _ident: &amp;Ident) -&gt; Option&lt;&amp;DeclProvenance&gt; { None }
fn get_provenance_by_name(&amp;self, _name: &amp;str) -&gt; Option&lt;&amp;DeclProvenance&gt; { None }
```

**Where it's built** — *not* in `assemble()`. Recording during `assemble` (import.rs:572) is too late for original names (mangling already ran, lib.rs:911-912) and misses stripped-but-error-relevant decls. Record **once, pre-mangle**, on the whole module set:

```rust
// import.rs
impl Resolutions {
    /// Record (path, original name, span, ident identity) for every named global
    /// declaration of every loaded module. Must run BEFORE `mangle`.
    pub(crate) fn record_provenance(&amp;self, sourcemap: &amp;mut BasicSourceMap) {
        for module in self.modules() {
            let module = module.borrow();
            for decl in &amp;module.source.global_declarations {
                if let Some(ident) = decl.ident() {            // owned clone, dropped below
                    let span = decl.span();                    // Spanned::span, span.rs:67
                    let span = (span.start &lt; span.end).then_some(span); // empty =&gt; synthesized
                    sourcemap.add_provenance(ident.downgrade(), module.path.clone(),
                        ident.name().to_string(), span);
                }
            }
        }
    }
}
```

Updated `compile_sourcemap_with_passes` sequence (deltas to lib.rs:924-960):

```rust
let sourcemapper = SourceMapper::new(root, resolver, mangler);
match compile_pre_assembly(root, &amp;sourcemapper, options, passes) {
    Ok((mut resolutions, keep)) =&gt; {
        resolutions.record_provenance(&amp;mut sourcemapper.sourcemap.borrow_mut()); // NEW (field is pub, sourcemap.rs:116)
        resolutions.mangle(&amp;sourcemapper, options.mangle_root);
        let sourcemap = sourcemapper.finish(); // finish() now also calls index_output_names()
        ...
```

`SourceMapper::finish` (sourcemap.rs:130-136) additionally calls `index_output_names()` — it runs *after* mangling, so upgrading each weak ident yields the **final output name**, giving `by_name` complete coverage **including unmangled root declarations** (today's gap, error.rs:243). The `Mangler`-proxy `add_decl` recording (sourcemap.rs:161-167) stays for back-compat but is subsumed.

Why keyed lookups stay valid post-compile: `CompileResult::clone` clones `syntax` (Ident clones share the Arc) and the sourcemap (WeakIdents point at the same allocations) — `provenance_of` keeps working on clones.

## 2.2 Robustness under later passes

- **Rename** (user passes, alias/const inlining via `alias.ident.rename(...)`, lower.rs:85-89): WeakIdent key unaffected; `DeclProvenance.name` intentionally stays the *source* name. `by_name` reflects names as of `finish()`; decls renamed later are reachable via `by_ident` only — exactly the right split (errors quote output names produced before `Final`; annotation uses idents).
- **Remove** (strip.rs:9-16, lower's `swap_remove`): side-table entries go stale but are never consulted (annotation walks the *final* decl list). No dangling anything thanks to Weak.
- **Reorder**: identity-keyed, order-independent.
- **Synthesize** (generics `generate_variants`, lib.rs:887; user-inserted decls): fresh idents miss the map → no comment; fresh `Spanned::from` nodes have the empty default span (span.rs:81-88) which `record_provenance` maps to `span: None` anyway. Uniform rule: *no provenance → no comment*. (Future extension: let passes call `add_provenance` themselves; deliberately out of v1.)
- **`use_count` invariant** (the trap from fact 4): the map holds zero strong clones at every point of the pipeline; add a regression test asserting stripping still removes an unused decl when `use_sourcemap(true)`.

## 2.3 Annotated output

**Mechanism (i) — writer in `wesl`, no wgsl-parse changes. Recommended.** Per-decl `Display` verified (fact 5). New `crates/wesl/src/output.rs`:

```rust
impl CompileResult {
    /// `to_string()` with a provenance comment above each declaration:
    /// `// package::bar::baz (src/shaders/bar.wesl:12)`
    /// Requires sourcemapping (`Wesl::use_sourcemap`, on by default);
    /// falls back to plain output when the sourcemap is absent.
    pub fn to_string_with_origins(&amp;self) -&gt; String {
        self.to_string_annotated(default_origin_comment)
    }
    /// Custom comment formatter; return `None` to skip a declaration.
    pub fn to_string_annotated(&amp;self, fmt: impl Fn(&amp;DeclLocation) -&gt; Option&lt;String&gt;) -&gt; String;
}

/// Default formatter: `// {path}::{name} ({file}:{line})`, degrading gracefully
/// when `file`/`line` are unknown.
pub fn default_origin_comment(loc: &amp;DeclLocation) -&gt; Option&lt;String&gt;;
```

Internals mirror `TranslationUnit::fmt` exactly (imports — empty after assembly, import.rs:573 starts from `default()`; directives `"\n"`-joined + blank line; non-Void decls separated by blank lines, trailing newline), inserting `fmt(&amp;loc)` lines before each decl that has provenance (`decl.ident()` → `sourcemap.get_provenance`). A local `HashMap&lt;&amp;ModulePath, Vec&lt;usize&gt;&gt;` of line-start offsets is built once per call (binary search per decl), avoiding both O(file) rescans and interior mutability. `ConstAssert`/`Void` decls have no ident → no comment (documented).

**Mechanism (ii) — trivia/comment nodes in wgsl-parse: assessed, rejected.** Comments are consumed inside logos callbacks (lexer.rs:207-224, 279-281); representing them would require token-stream surgery, LALRPOP grammar changes, a trivia side-table or a leading-trivia field on every node (breaking `PartialEq`, serde, tokrepr derives), plus Display changes across syntax_display.rs — and it still wouldn't *generate* origin info, only carry source comments. Nothing about origin annotation needs an AST representation. Revisit only if round-tripping user comments becomes a requirement.

## 2.4 File paths in comments

`DeclLocation.file` = `SourceMap::get_display_name(path)`, which `SourceMapper` records from `Resolver::display_name` at load time (sourcemap.rs:146-150). `FileResolver::display_name` returns the real resolved filesystem path string, including the `.wesl`/`.wgsl` fallback logic (resolve.rs:160-167), e.g. `src/shaders/bar.wesl` — precisely the string in the target format. `VirtualResolver`/packages yield `None` → comment degrades to `// package::bar::baz` (+ `:12` if line known). `fs_path` remains reserved for build-script dependency tracking (resolve.rs:51-55) and is not used here.

## 2.5 Error-diagnostic improvements

Already working today (state precisely): if an error carries a span and the sourcemap knows the module source, annotate-snippets renders the caret with line numbers (error.rs:557-579). V2 adds:

1. **Root/unmangled declarations resolve** in `Diagnostic::with_sourcemap` (error.rs:197-221) and `unmangle` (error.rs:248+) because `by_name` now covers every output declaration — fixing the documented issue at error.rs:243. Minor user-visible delta: validation errors mentioning root decls will now display qualified `package::main::foo` names — call out in CHANGELOG.
2. **Decl-span fallback**: in `with_sourcemap`, before the name remap, when `detail.span.is_none()` and the declaration name is known, set `detail.span` from `get_provenance_by_name(name).span` (coordinates match the module source that the same lookup installs into `detail.source`). Errors that today print only "in declaration of `X` in mod" gain a real source snippet pointing at the declaration header.
3. **Programmatic API** (`provenance_of`, `decl_location`) for tooling — e.g. mapping naga/driver errors on the emitted WGSL back to WESL files, previously impossible since no spans were recorded anywhere.
